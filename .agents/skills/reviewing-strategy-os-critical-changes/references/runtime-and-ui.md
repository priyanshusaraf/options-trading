# Runtime and UI review

For local runtime evidence, confirm mock provider, paper execution, empty live acknowledgement, disabled dotenv, temporary database, and no ARM. Never accept a local check that used the shipped environment or live state.

For UI changes, require the operator flow in a running browser, desktop and 390×844 inspection, console and network checks, loading/error/empty states, and a reviewed screenshot. Check that every displayed value is truthful or visibly unknown, REST remains centralized, and no second WebSocket exists. Frontend implementation remains an owner gate unless explicitly authorized.
