# Browser evidence

For a meaningful UI flow, perform the operator journey rather than only loading a route. Verify the exact served build, URL, protocol, port and route before sharing a preview. Inspect the layouts in the current assignment, console errors, network failures or polling, loading/error/empty states, and a screenshot. Include 390×844 when mobile is in scope; respect an explicit desktop-only assignment.

Exercise the affected controls and trace their real API effect. Verify values are truthful or visibly unknown. Label fixtures and mocked boundaries. A screenshot or listening port does not prove a working journey. A browser check does not itself expand implementation authority; an existing explicit frontend assignment already supplies that authority.
