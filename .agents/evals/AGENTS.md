# Bounded harness evals

These files test the agent operating model; they are not implementation tasks. Do not run the normal repository startup protocol, read `CURRENT.md` or a task capsule, inspect git or application state, run commands or tests, browse, edit, deploy, or delegate.

Answer from the already loaded repository instructions and skill descriptions. When the prompt names a repository skill, read that `SKILL.md` completely and at most one directly linked reference. Make no other tool calls. Keep the final answer at or below 180 words and address only the hypothetical prompt.
