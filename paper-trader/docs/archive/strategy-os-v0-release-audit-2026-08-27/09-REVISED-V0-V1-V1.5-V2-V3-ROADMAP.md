# Revised V0 / V1 / V1.5 / V2 / V3 roadmap

## Version decision

The 24 August architecture remains the long-term object model. This roadmap inserts
V0 and V0.1 before execution-capable V1. It changes release eligibility and order,
not canonical identities.

## V0 — research, robustness and deterministic signals

### V0-A — release profile and hard execution denial

Outcome: one V0 capability manifest, API/research/monitor roles, no execution worker,
unreachable order/capital/position mutations, V0 navigation and negative route tests.

Reuses: Phase 1 tenancy, Phase 2 service/concurrency, paper/live separation, current
provider connection and frontend shell. This is the first executable capsule.

### V0-B — verified/versioned strategy language

Outcome: all 125 components have retrievable specifications and exact
keep/v2-replace/refuse decisions; V0 exposes only accepted versions. Complete
external math, warmup, validity, parameter/output and state conformance.

Reuses: accepted Phase 5 registry/resource/research runtime and the current
post-Phase-5 accuracy replan.

### V0-C — canonical builder and research spine

Outcome: create/select/edit/version/admit a V0 strategy in the node canvas; run its
exact graph through data compilation, backtest job, result persistence and evidence
reopen. No fixed repository graph or second strategy key path.

Reuses: Phase 3 IR, Phase 5 editor/backtest/research lineage, graph APIs and claims.

### V0-D — Zerodha, static scopes and research data

Outcome: user-specific read-only Zerodha connection, static scopes, canonical
instrument mappings, India VIX, options-chain/OI/IV/depth/order-flow facts and exact
captured-history limits. No order/account-fund capability.

Reuses: Phase 1 provider connections, Phase 4 market truth, existing Kite provider,
options picker/cache and first-party derivative nodes.

### V0-E — chart, annotations and historical replay

Outcome: approved professional chart route, saved workspace, normalized level/zone/
trendline/channel/Fibonacci semantics, lock/version lifecycle and temporally honest
replay. Visual-only drawings remain clearly non-executable.

Reuses: graph presentation-state separation and the Precision Slate direction.

### V0-F — robustness lab

Outcome: locked OOS, walk-forward, bounded optimisation, DSR/PBO/N-eff, parameter
neighbourhood, sensitivity/surface, seeded Monte Carlo, baseline comparison,
reproducible jobs and evidence UI.

Reuses: existing research pipeline and immutable ledgers; adds missing neighbourhood
and Monte Carlo methods.

### V0-G — forward monitoring, signals and review

Outcome: monitoring-only assignment over the same graph/incremental state; exact
BUY/SELL/EXIT/HOLD transitions, dedup/cooldown/stale/restart evidence, explanation and
append-only user review. No deployment/order authority.

Reuses: Phase 5 incremental runtime, snapshots, existing SignalEvent concept and
research review patterns.

### V0-H — Precision Slate convergence

Outcome: canonical frontend adopts the Precision Slate information architecture and
visual builder over real APIs. Responsive owner workflow, truthful loading/error/
Unknown states, accessible evidence and bounded performance.

Reuses: the current integrated API client and external prototype design; fixture
values are removed rather than copied into product truth.

### V0-I — security, analytics, operations and deployability

Outcome: beta auth/onboarding, secrets, V0 service topology, PostgreSQL roles/heads,
workers, health, observability, quotas, backup/restore, rollout/rollback, analytics,
privacy/terms/support and external chart/data/counsel gates.

Reuses: Phase 1/2 tenancy/concurrency, Phase 5 packaging, current CI/deploy guards and
Phase 12 contract.

### V0-J — golden five, strategy pack and release review

Outcome: A/B/D/E/F reach declared research/signal eligibility; owner strategies run
through the same harness; cross-capability adversarial matrix, exact build/browser/
smoke/capacity and independent V0 review. No profitability claim.

## V0 release ladder

```text
V0-A/B/C/F subset → owner dogfood
V0-A through H on controlled data → demo
V0-A through I + exposed benchmark evidence → founder-assisted beta
Gate C legal/data/billing/ops → paid private beta
Gate D scale/support/rehearsal → public beta
```

## V0.1 — feedback hardening and bounded expansion

V0.1 is driven by cohort evidence and may include:

- Dynamic Watchlists and Benchmark C;
- richer instrument/provider/data coverage;
- additional verified nodes and annotation semantics;
- improved strategy templates/onboarding;
- result/report UX and support tools;
- measured capacity and cost reductions;
- low-risk chart semantics users actually request.

It does not reintroduce public execution automatically.

## V1 — execution-capable Strategy OS

V1 consumes accepted V0 strategy/research/monitoring facts and adds controlled
execution eligibility:

- resolved deployment binding and Execution Product Policy;
- provider price coherence and latency/preflight;
- target sizing and the already-built deterministic capital admission/reservation;
- proposal/approval/revalidation where product positioning requires it;
- account leases, paper/live authority, order/fill/position/money attribution;
- reconciliation, protection, degraded-state exits and execution operations;
- Dynamic Watchlists if not already accepted in V0.1;
- execution-specific A/C/E/F evidence and final V1 review.

Existing Phase 5 capital work returns here without being rebuilt. The old Phase 6–13
documents remain source contracts, but their implementation order is rederived after
V0 evidence.

## V1.5 — certified liquid index-options execution

- narrow, liquid, single-leg NIFTY/BANKNIFTY/SENSEX surface subject to current
  point-in-time listing and liquidity;
- exact selector policy/receipt and held-contract exit;
- conservative order/protection/reconciliation;
- provider/broker conformance, options latency/liquidity and recovery;
- no broad stock/commodity/multi-leg promise.

V0 options research does not certify V1.5 execution.

## V2 — workflows, diagnostics and richer intelligence

- deterministic Strategy Workflows;
- Strategy Diagnostics and Counterfactual Lab;
- richer fundamentals/events and Dynamic Universes;
- deeper derivatives/OI/VIX and portfolio research;
- broad annotation replay/backtesting when evidence justifies it;
- richer adaptive sizing and evidence-grounded recommendations;
- additional providers and professional collaboration where demanded.

## V3 — AI, ecosystem and institutional expansion

- AI Research Agent and image/freehand interpretation;
- ML/model nodes;
- marketplace, managed models and creator economics under appropriate legal structure;
- portfolio-of-strategies and advanced Kelly/allocation;
- international markets, brokers and institutional connectivity;
- queue/fill/low-latency models only where data and demand justify them.
