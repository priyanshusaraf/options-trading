Runtime

  • ·DigitalOcean Bangalore VPS 64.227.191.162, 1 GB. Engine runs 24/7 under systemd.
  • ·UI is tailnet-only at paper-trader.taile25969.ts.net. Keep the Mac engine off — one live engine only.
  • ·Daily routine: open the UI on the phone, connect Kite (the token expires ~06:00 IST), then ARM.
  • ·Deploy is a whole-tree rsync from the Mac plus systemctl restart. The VPS has no git.
  • ·The engine is disarmed on every process start, by design.

Standing risks

  • !!Deploy clobbers the VPS .env — twice now. The rsync overwrites it with the Mac's copy, dropping PT_SERVE_FRONTEND, so every GET / 404s while /api/health stays green. Fix is --exclude .env; the post-deploy check must curl /, not just health.
  • !DB bloat — paper_trader.db is ~45 MB and grows ~5 MB/day from unbounded option_data, signal_events and equity_snapshots. Redesign undecided.
  • !1 GB droplet is tight — the 2026-07-23 outage was two memory leaks, both fixed and deployed. A resize to 2 GB is an owner action.
  • !Thin live sample — the live order path is proven (50 real orders, 34 real trades, 2026-07-13 → 2026-07-22), but 34 trades over 10 days says nothing about edge. Corrected 2026-07-28; this line previously claimed the path had never fired.
  • !!Equity curve overstates real equity ~2× — the ledger is pinned to the synthetic ₹50,000 base and the auto-reanchor cannot fire on an account that has already traded. Reported ₹50,744 vs. a real account net of ₹14,236–₹27,441.
