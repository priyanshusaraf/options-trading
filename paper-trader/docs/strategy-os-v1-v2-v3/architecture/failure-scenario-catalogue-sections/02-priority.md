## Status rule

A scenario moves to ALREADY SAFELY HANDLED only when:

- the real boundary has a permanent test;
- a deliberate guard mutation makes that test fail where critical;
- the fix restores the test;
- transitive evidence remains current;
- deployment impact is recorded.
