# Desktop UI direction

Latest owner direction controls the interface. Phone responsiveness is deferred. Prioritize the desktop research workflow and visual quality.

- Preserve the three-pane sketch: Watchlist/Runs upper-left, chart/results upper-right, full-width builder below. Draggable width/height, minimum sizes, expand/restore, reset and saved layout preferences.
- New strategy opens Start fresh / Use a preset. Presets have their own section. Hide internal identifiers and create an internal project only when needed for a confirmed action.
- Use quieter typography, sentence case, modest weights, thin structural dividers. Remove decorative left-edge selection stripes, heavy boxes, repeated eyebrows/subheadings and marketing/helper copy.
- Remove Research studio/design-preview title clutter and instructional footer. Keep prototype truth/limits in an About/info view; never show invented performance as real.
- Compact and align the strategy/dataset/timeframe controls. Let experienced users hide workspace/context/builder toolbars and reveal them with an accessible control or shortcut.
- Restore a gridded connected-node canvas and a contextual sidebar for the selected component. Shift+A opens the add-node palette only outside text-entry controls. Preserve keyboard focus and Escape behavior.
- Prioritize real pan/zoom, price-axis scaling, crosshair/candle inspection and working expansion. Target TradingView Advanced Charts, subject to its licence; Lightweight Charts is an available interim rendering library, not its full drawing toolkit.
