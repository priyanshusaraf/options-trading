# Phase 4 adversarial contract correction

The matrix owner found a real architecture contradiction before writing a test. The Phase 4 adversarial row required successful v2 claim and reclaim, while the accepted CUR-H3 boundary forbids v2 claim or reclaim until a Phase 5 attribution schema and later runtime enablement exist. The current public seam correctly verifies authority and refuses before claiming work.

This capsule separates the obligations without discarding either one. Phase 4 owns fail-closed containment on the current non-executable v2 path. Phase 5 retains the successful operational lifecycle under `P5-ADV-006-RUNTIME`, after the attribution schema and a separately generated runtime capsule. The schema itself remains non-enabling.

The owner must change contracts, not code. Phase 4 remains open, the adversarial matrix remains blocked until this correction is accepted, and Phase 5 remains blocked.
