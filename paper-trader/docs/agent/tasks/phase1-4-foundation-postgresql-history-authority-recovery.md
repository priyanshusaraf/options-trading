retained PostgreSQL historical start to reproducible authoritative bytes or
returns an explicit support decision for root and owner review. It cannot edit
or resume the migration implementation.

`EXPLICIT_MATRIX_REVISION_REQUIRED`. Root accepted the revision at
`.agent/runs/phase1-4-foundation-critical-closure/postgresql-history-recovery-acceptance.json`.

deployed, production, or externally promised state condition.
