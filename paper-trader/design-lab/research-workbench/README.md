# Strategy OS V0 research workbench concept

This standalone HTML/CSS/JavaScript concept explores an invited-user journey from sign-in through strategy composition, data compatibility, backtesting, robustness review, evidence capture, and attributable research alerts.

Open `index.html` directly in a browser. It uses embedded example data and makes no network, API, signal, or order requests.

The example opening-range study covers RELIANCE and HDFCBANK with NIFTY as a price-only cross-instrument filter. Its deliberately incomplete HDFCBANK fixture demonstrates how a required equity volume field blocks every results screen until the user selects the complete example dataset.

The central rule sheet is a trader-readable projection of one revisioned strategy. Technical identity details are available only on request. The concept includes a genuinely empty draft, native editing controls, visible focus, a compact mobile step selector, a chart text alternative, precise missing-data feedback, and keyboard-usable navigation. These design provisions have not been tested as a WCAG conformance claim.
